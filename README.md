# IronPulse Fitness Club Website 🏋️‍♂️⚡

A modern, high-performance, responsive landing page and web experience for **IronPulse Fitness Club** — Brookhaven's premier strength training, functional fitness, and recovery community.

---

## 🌟 Highlights & Features

- **Dynamic Hero Section**: High-impact visuals, bold typography, call-to-action badges, and member metrics counter.
- **Facility Showcase**: Interactive gallery highlighting strength floor, cardio deck, turf sprint track, boxing zone, yoga studio, recovery sauna, and smoothie bar.
- **Class Schedules & Filter**: Searchable and filterable weekly class timetables across HIIT, Strength, Yoga, Spin, and Boxing.
- **Interactive BMI Calculator**: Instant metric and imperial body mass index calculator with customized fitness advice.
- **Trainer Profiles**: Certified coaches with bios, specialties, and social links.
- **Member Transformations**: Interactive before-and-after photo comparisons demonstrating real member success stories.
- **Tiered Membership Pricing**: Flexible membership plans (Basic, Pro, Elite) with monthly/annual billing toggles and feature breakdown.
- **Interactive Tour & Booking**: Built-in 7-day trial signup modal and contact inquiry form with form validation.
- **Responsive & Accessible**: Mobile-first design, fluid layouts, semantic HTML5, and Schema.org structured data for SEO.

## 🚀 Getting Started

### Option 1: Direct File Preview
Simply double-click or open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local Node Server
Run the built-in HTTP server:

```bash
# Start server
node serve.js
```

Then visit [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ Tech Stack

- **HTML5**: Semantic tags, OpenGraph meta tags, Schema.org JSON-LD structured data.
- **CSS3**: Custom design tokens, CSS Grid, Flexbox, glassmorphism, animations, responsive breakpoints.
- **Vanilla JavaScript (ES6+)**: Zero external JavaScript frameworks for ultra-fast load times.
- **Font Awesome 6**: Vector icons for fitness categories and UI navigation.
- **Node.js**: Lightweight local static file server.
